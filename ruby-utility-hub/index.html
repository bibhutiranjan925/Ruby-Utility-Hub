Toolkit

Eight tools, one dashboard

Fill in a card, press the button, and the Ruby backend answers. Invalid input is rejected with a clear message instead of a wrong result.

01

String Repeater

Repeats text with Ruby's * operator. Zero and an empty string are allowed.

Optional — leave empty to repeat nothing.
Whole number from 0 to 1000.
Sending to Ruby…

02

Circle Calculator

Perimeter and area from a radius, using 2 * Math::PI * r and Math::PI * r².

0 or more. Decimals welcome (try 2.5).
Sending to Ruby…

03

Name Reverser

Puts the last name before the first name. Blank or space-only names are refused.

Sending to Ruby…

04

File Extension Extractor

Uses Ruby's File.extname. Handles .tar.gz, hidden files and trailing dots.

Nothing is uploaded — Ruby only reads the name.
Sending to Ruby…

05

Greatest of Three Numbers

Compares three numbers with Array#max. Negatives, decimals and equal values all work.

Sending to Ruby…

06

Odd Numbers

Counts down with downto and prints only odd values — 9, 7, 5, 3, 1 by default.

Leave empty for the original exercise (10 down to 1).
Sending to Ruby…

07

Number Checker

If either integer is 20 the answer is true; otherwise it returns their sum.

Sending to Ruby…

08

Temperature Checker

True when one temperature is below 0 and the other is above 100 — both arrangements are checked.

Sending to Ruby…

How it works

Your input takes a round trip to Ruby

No calculations are faked in the browser — the maths, the validation and the wording all come from the Ruby backend.

  1. 1

    You type in the browser

    HTML builds the cards, CSS styles them responsively, and JavaScript collects the values from the form you pressed.

  2. 2

    JavaScript calls a Ruby function

    A fetch request goes to /api/…, where Vercel runs the matching .rb file as a serverless function.

  3. 3

    Ruby answers with JSON

    The function validates the input, applies the original formula and returns JSON, which JavaScript renders into the result panel.

  • HTML5
  • CSS3
  • JavaScript (ES2020)
  • Ruby 3.3
  • Vercel Functions
  • No frameworks
  • No database
  • No API keys
Run locally

Three commands and it is up

The same Ruby handlers run on your machine, so testing here is a faithful preview of the deployed site. You need Ruby 3.1 or newer.

  1. Install the one gem: gem install webrick
  2. Start the server: ruby dev_server.rb
  3. Open http://localhost:3000 and use the cards.

terminal

# 1. install the only gem this project uses
$ gem install webrick

# 2. start the local Ruby server (project root)
$ ruby dev_server.rb

# 3. open the dashboard
$ http://localhost:3000
